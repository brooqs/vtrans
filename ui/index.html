Failed files

These files are not tried again and are not counted in the queue. Retry puts one back; Ignore moves it to the ignore list, where it stays out of the way for good. "insufficient saving" is not a failure: it means the file is already efficient enough.

Ignored files

These are left out of the queue entirely. vtrans adds a file here itself when it would refuse it on every run (streams that cannot be written); anything else here was put there by hand. Un-ignore returns a file to the queue.

Trash

Replaced originals wait here until you empty the trash, so replace mode can be undone one file at a time. Restore puts the original back where it was, deletes the AV1 file that took its place, and adds the file to the ignore list so it is not encoded again; un-ignore it when you want that.

Library health

Reads every file in the index with ffprobe and lists the ones with a real problem. It only reads - nothing is changed. Files already processed are checked too, so problems show up even where nothing else would look. Ordinary observations (already AV1, cover art) are left out here; use Diagnose on a single file to see everything about it.
